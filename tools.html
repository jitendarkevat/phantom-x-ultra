⌬ Security Headers Reference

Use this checklist on a site you own or are authorized to assess.

  • Content-Security-PolicyRestricts which content can load.
  • Strict-Transport-SecurityEncourages HTTPS-only access.
  • X-Content-Type-Options: nosniffReduces MIME-sniffing risk.
  • Referrer-PolicyControls referrer information.
  • Permissions-PolicyLimits selected browser capabilities.

This is a reference checklist, not a live remote scan.
